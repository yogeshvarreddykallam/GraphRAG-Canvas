# GraphRAG-Canvas

> Knowledge-Graph-Enhanced Retrieval-Augmented Generation for Canvas LMS course content.

An extension of the original [CMPSC132-Canvas-RAG](https://github.com/yogeshvarreddykallam/CMPSC132-Canvas-RAG) system, augmented with a formal OWL ontology, RDF triple store, and NetworkX-based graph traversal layer — implementing the GraphRAG paradigm on top of a FAISS vector index.

---

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                        User Query                           │
└──────────────────────────┬──────────────────────────────────┘
                           │
              ┌────────────▼────────────┐
              │   spaCy PhraseMatcher   │  ← seeded from OWL ontology labels
              │   Concept Extraction    │
              └────────────┬────────────┘
                           │  detected concept URIs
              ┌────────────▼────────────┐
              │   NetworkX KG Traversal │  ← canvas_kg.graphml
              │   K-hop Neighbour Walk  │    (relatedTo + hasPrerequisite edges)
              └────────────┬────────────┘
                           │  expanded concept labels
              ┌────────────▼────────────┐
              │   Query Expansion       │  "binary search tree" →
              │   (append neighbours)   │  "binary search tree avl tree
              └────────────┬────────────┘   binary tree sorting big-o"
                           │
              ┌────────────▼────────────┐
              │   FAISS Vector Search   │  ← sentence-transformers all-MiniLM-L6-v2
              │   (IndexFlatIP cosine)  │
              └────────────┬────────────┘
                           │  top-2K candidate chunks
              ┌────────────▼────────────┐
              │   KG Boost Re-ranking   │  +score if chunk contains
              │                         │   query/neighbour concepts
              └────────────┬────────────┘
                           │  top-K KGHit results
              ┌────────────▼────────────┐
              │   Ollama LLM (llama3)   │  ← context-injected prompt
              └────────────┬────────────┘
                           │
                    Streamed Answer
```

## Semantic Architecture — OWL Ontology

The ontology (`ontology/canvas_kg.ttl`) is authored in **OWL/Turtle** and defines:

**Classes**
| Class | Description |
|-------|-------------|
| `ckg:Concept` | Top-level course concept |
| `ckg:DataStructure` | Named data organisation pattern (subclass of Concept) |
| `ckg:Algorithm` | Computational procedure (subclass of Concept) |
| `ckg:ProgrammingConstruct` | Language-level feature (subclass of Concept) |
| `ckg:Module` | Canvas LMS module/week |
| `ckg:Assignment` | Graded task belonging to a module |
| `ckg:SourceChunk` | Indexed text passage from a course file |

**Object Properties**
| Property | Type | Description |
|----------|------|-------------|
| `ckg:relatedTo` | Symmetric | Concepts that co-occur or share semantic proximity |
| `ckg:hasPrerequisite` | Transitive | Concept A requires understanding Concept B first |
| `ckg:belongsToModule` | — | Links a concept to its primary teaching module |
| `ckg:mentionedIn` | — | Concept appears in a SourceChunk |
| `ckg:tests` | — | Assignment tests understanding of a concept |

**Seed individuals** include 25 CMPSC 132 core concepts: LinkedList, Stack, Queue, BinaryTree, BST, AVLTree, Heap, HashMap, Graph, Recursion, DynamicProgramming, Sorting, BigO, OOP, Inheritance, Polymorphism, Iterator, DFS, BFS, and more — all with `hasPrerequisite` and `relatedTo` edges pre-populated.

```

├── ontology/
│   └── canvas_kg.ttl          # OWL ontology (Turtle format)
```

## Setup

```bash
# 1. Install dependencies
pip install -r requirements.txt
python -m spacy download en_core_web_sm

# 2. Scrape Canvas (requires Canvas API token in .env)
python scrape_canvas.py

# 3. Build FAISS index
python build_index.py

# 4. Build Knowledge Graph
python kg_builder.py

# 5. Launch the app
python app.py
# → http://127.0.0.1:7860
```

**Environment variables** (`.env`):
```
CANVAS_API_KEY=your_canvas_token
CANVAS_BASE_URL=https://canvas.psu.edu
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
```

## What GraphRAG Adds Over Vanilla RAG

| Feature | Vanilla RAG | GraphRAG-Canvas |
|---------|-------------|-----------------|
| Retrieval signal | Cosine similarity only | Cosine + KG concept boost |
| Query understanding | Lexical/semantic | Ontology-grounded concepts |
| Context awareness | None | Prerequisite + related concept graph |
| Explainability | Source chunks | Source chunks + KG expansion trace |
| Schema | None | Formal OWL ontology |

## Tech Stack

- **RDFLib** — OWL ontology parsing, RDF triple store, Turtle serialisation
- **NetworkX** — runtime graph traversal, GraphML persistence
- **spaCy** — PhraseMatcher-based concept extraction
- **FAISS** — approximate nearest-neighbour vector search
- **sentence-transformers** — `all-MiniLM-L6-v2` embeddings
- **Ollama** — local LLM inference (llama3.1:8b)
- **Gradio** — web UI
